# 我要当国王 — Godot 4.7 原型

剑与魔法·俯视角 2D 自由地图基地攻防原型。**手机优先、PC 可玩**，单人对 AI 镜像。

> 当前为「按定稿设计」重写版（Godot 4.7.2，占位色块美术），数值见 `design.md`。

## 核心循环
一无所有开局 → **采集**（砍树/挖石/采铁）→ **建大本营** → 领地扩张 → **建围墙+防御塔** → **升级大本营**（解锁采铁+兵营）→ **建兵营出兵** → **带兵拆家**。

## 操作
| 动作 | 键盘（PC） | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 左下虚拟摇杆 |
| 攻击（自动索敌：近剑/远弓/采资源） | 空格 / 鼠标左键 | 右下「攻击」按钮 |
| 重新开始 | R | — |

局内右侧按钮：**建家/围墙/防御塔/兵营**、**升级大本营/升级兵营**；左上角「小兵：驻守」切换 **跟随/驻守**。

## 胜利条件
先摧毁敌方大本营者胜。**8 分钟后**全体小兵每 1 分钟 +15% 伤害，加速收尾（不硬性比血量）。

## 已实现
- 资源：木/石(9血)、铁(45血)；铁需大本营升级后可采；采空 60 秒原位刷新
- 建筑解锁链（部落冲突式）：建家→塔+围墙→升家→兵营→骑兵
- 建造耗时：家10s/墙2s/塔5s/兵营5s/升家10s/升兵营10s；建造中未完工=10血可被打断，打断掉材料到地上（双方可捡）
- 建造判定：候选点吸附最近空格；领地内+空地；脚下绿/红预览；围墙被占提示失败
- 领地：大本营为中心初始约120px，每建一建筑+40px；两家开局不相邻
- 出兵：每3秒1个（上限3），死亡10秒补；兵营≤2座；升级→全体变骑兵
- 小兵：剑士(近战)/弓手(远程过墙)/骑兵(高阶)；驻守/跟随切换
- 野怪：弱群(2~3只，掉木石)、强群(5~6只，掉铁)；区域游荡、近身追击
- AI：完全镜像玩家建造链
- 界面：开始菜单/教程/局内HUD/结算

```
  resource_node.gd   资源节点（木石铁）

  projectile.gd      箭矢

  hud.gd             界面
  world.gd           地图背景

design.md            设计定稿（含数值表）
```
